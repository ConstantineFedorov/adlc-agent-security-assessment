# Security Policy

## Scope

This repository is an educational security-assessment project documenting controlled experiments and guardrail testing in a local ADLC lab.

It is not a production security framework and does not provide a guarantee that an AI agent is secure.

## Reporting a concern

If you find a sensitive issue in this repository, please do not publish secrets or personal data in a public issue. Contact the repository owner privately through a GitHub communication channel and include:

- a concise description of the issue;
- the affected file or component;
- steps to reproduce using the educational lab;
- observed and expected behavior;
- evidence with secrets and personal data removed.

## Safe research

- Test only systems you own or are explicitly authorized to assess.
- Use isolated, controlled environments and harmless canary values.
- Do not commit API keys, tokens, credentials, private logs, or local model files.
- Share only the minimum reproducible evidence needed to explain a finding.
